# MacDotfiles

macOS dotfiles with Gruvbox Dark theme. Ported from [ArchDotfiles](https://github.com/brvtl/ArchDotfiles).

## Quick Start

```bash
git clone git@github.com:brvtl/MacDotfiles.git ~/code/MacDotfiles
cd ~/code/MacDotfiles
./install.sh
```

## What's Included

- **ZSH** - Oh My Zsh + Starship prompt + aliases/functions
- **Alacritty** - GPU-accelerated terminal
- **Git** - 1Password SSH signing, GitHub CLI credentials
- **LazyGit** - Terminal UI for git
- **Doom Emacs** - Go, Python, JS/TS, Terraform, Magit
- **Starship** - Cross-shell prompt
- **Claude Code** - AI dev tool config + agents
